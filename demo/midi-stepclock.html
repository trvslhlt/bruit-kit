StepClock + StepTrack

One shared createStepClock driving two independent createStepTrack rows — an OscillatorSynth and a NoiseGenerator — instead of each row owning its own clock. Row B starts inactive; "Enable Row B" only takes effect at the start of the next 8-step cycle, not immediately, proving a row can join mid-performance without resyncing anything.
