PhaseDistortionSynth

Casio CZ-style phase distortion: a linear phase ramp is warped through the curve below *before* it's used to index a sine lookup — reading the same sine at an uneven rate produces extra harmonics. Drag the curve to reshape the tone; "Distortion amount" blends between a plain sine (0) and the fully-warped curve (1). Try the default sawtooth-ish curve, or draw a step for a hollow/square-ish tone.
